# キャラ画像フォルダ（利用者が権利を持つ画像用）

このフォルダに `キャラID.png`（または .jpg / .webp）を置き、

```
node tools/build_portraits.js
```

を実行すると `js/portraits.js` に data URL として書き出され、開発版・単一ファイル版の両方でそのキャラの全カードに表示される。
キャラ ID はゲーム内「図鑑 → キャラID一覧」または `js/data.js` の `CHARACTERS` を参照（例：`isagi.png`、`rin.jpg`、`noa.webp`）。
ファイル名をキャラ名（例：`潔世一.png`）にしても取り込める。

- 推奨サイズ：160×200 px 程度（縦長）。1 枚 200KB 以下を推奨（単一ファイル版のサイズに直結する）。
- 原作の画像はリポジトリに同梱しない。このフォルダの中身（README 以外）は `.gitignore` で除外されている。
- ゲーム内の「画像を設定」「画像パック一括取り込み」は端末内（localStorage）保存で、こちらより優先される。
