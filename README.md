# BLUE LOCK PWC : EGOIST ROGUELITE

> 本ゲームは原作のブルーロックを忠実に再現した、『ブルーロックPWC』の改変版である

漫画『ブルーロック』原作準拠の **超高難度ローグライト育成サッカーシミュレーション**（SPA）。
依存ライブラリなしの HTML / CSS / JavaScript で動作する。

『ブルーロックPWC』が 1 回の育成で完結するのに対し、本作は **編ごとに 1 回の育成** を積み重ねる。第一編を生き残った選手は「卒業生」として保存され、第二編はその卒業生で、第三編は第二編の卒業生で……と繰り返し、**第四編を卒業した 5 人を決戦メンバーに選んで U-20 ワールドカップに挑む**。決戦では局面ごとに起用選手を選び、世界一で 5 人全員が殿堂入りする。

## すぐに遊ぶ

- **単一ファイル版**：`dist/bluelock-pwc-egoist.html` をブラウザで開くだけ（CSS/JS 全インライン。フォントのみ Google Fonts、未接続時はシステムフォント）。
- **開発版**：`python3 -m http.server 8080` → http://localhost:8080/ （`index.html`）。
- セーブは `localStorage`（キー `bl_pwc_egoist_save_v5`）。行動のたびに不可逆で上書きされる。v4 以前のセーブはメタデータ（カード・ジェム・実績・殿堂）だけを自動で引き継ぎ、進行中の RUN は破棄される。

## 進行の流れ（編ごとに 1 回の育成）

| 編 | 参加資格 | 節（週数） | 編末の足切り | 生き残ると |
| --- | --- | --- | --- | --- |
| 第一編 一次選考（12週） | 所持カード | 入寮テスト（即時）→ vs X（3）→ Y（3）→ W（3）→ V（3） | 合計 280 ＆ 2勝以上 ＆ 最終戦勝利 | 卒業生（第一編）として保存 |
| 第二編 二次選考（11週） | 第一編の卒業生 | 100ゴール（2）→ 3rd 凛（3）→［敗北時］2対2（即時）→ 3rd 國神・千切・玲王（3）→ 4th 凛（3） | 合計 700 | 卒業生（第二編） |
| 第三編 三次選考（8週） | 第二編の卒業生 | トライアウト（4）→ U-20日本代表戦（4） | 合計 1,800 | 卒業生（第三編） |
| 第四編 新英雄大戦（12週） | 第三編の卒業生 | クラブ選択 → 4戦（各3週） | 累積年俸 1.6億円 | 卒業生（第四編）＝決戦メンバー候補 |
| 第五編・決戦 U-20 W杯（12週） | 第四編の卒業生 **5 人** | GL ナイジェリア／フランス／イングランド → QF ドイツ → SF スペイン → 決勝 フランス（各2） | GL 3戦2勝、決勝T 勝利必須、決勝 3対0 | 5 人全員が殿堂入り |

- 卒業生は能力・スキル・固有覚醒・年俸・Cash を引き継ぐ。編ごとに育成方針（決定力／戦術／快速／バランス）とアドバイザー・相棒を選び直す。
- 途中で除籍された卒業生は抹消される（第一編からやり直し）。決戦の敗退は卒業生を失わない（敗退回数を記録）。
- 決戦は 5 人同時に練習し、Climax ごとに起用選手と選択肢を選ぶ。同じ選手の起用は全 18 局面のうち 4 回まで（永続強化で最大 6 回）。故障で健全な選手が 3 人未満になると敗退。
- 編末には足切り判定に加え、合計ステータス ÷ 編基準値（170 / 700 / 2,500 / 6,000 / 20,000）による編評価ランク（SS ≥ 3.0 / S ≥ 2.2 / A ≥ 1.6 / B ≥ 1.2 / C ≥ 0.9 / D）。

## 永続強化（RUN を跨いで蓄積するもの）

| 系統 | 内容 | 通貨 |
| --- | --- | --- |
| 卒業生 | 編を生き残った選手そのもの（第四編卒業 ×5 で決戦） | — |
| エゴ強化（10種） | 練習理論（成長 +2%/Lv, max10）／入寮前トレーニング（初期値 +2%/Lv, max10）／回復設備／ゾーン誘導（FLOW +1%/Lv）／覚醒理論（閾値 −2%/Lv）／化学反応の場／購買部コネ／代理人契約（年俸 +3%/Lv）／再起の契約（補償 +10%/Lv）／決戦の采配（起用上限 +1/Lv, max2）。費用 = 基本 × (Lv+1)、総額約 46,650 ジェム | Ego Gems |
| 星上げ | カードの段階を最大 +3（★8 まで）。初期値・成長補正が上の段階の基準値になる。費用 ★2 60 / ★3 150 / ★4 400 / ★5 900 / ★6 1,800 / ★7 3,600 / ★8 7,200 | エゴ・ピース |
| 限界突破 | 同一カード再排出ごとに初期値 +5%・成長 +3%（上限なし） | スカウト／交換所 |
| 熟練度 | キャラごとの累積 XP（卒業 +1、決戦制覇 +3）。Lv（閾値 0/1/3/6/10/15/21/28/36/45/55）ごとに成長 +1%・初期値 +1%。同キャラの全カードに適用 | プレイ |
| アドバイザー・実績 | 実績で解放されるアドバイザー 7 名、実績 37 種（合計 13,300 ジェム超） | プレイ |

エゴ・ピースは、限界突破時（★1 2 … ★8 150）、卒業時（10 × 編番号）、除籍時（3 × 編番号）に獲得する。

## 相棒と化学反応

- RUN 開始時に所持カードから相棒を 1 枚選べる（PWC のサポート枠に対応）。相棒の主属性の成長が +1.5%＋0.5%×段階 上がる。相棒は育成されない。
- 原作ペア（潔×蜂楽、潔×凪、凪×玲王、千切×國神、凛×冴、潔×凛、潔×馬狼、凛×士道、蟻生×時光、二子×蜂楽、雪宮×氷織、烏×乙夜、カイザー×ネス、ノア×潔、國神×雷市、我牙丸×五十嵐、ロキ×シュヴァリエ、スナッフィー×馬狼、ラヴィーニョ×凪、プリンス×千切、黒名×雪宮、愛空×閃堂、テディ×アチャンポン、三笘×潔）は追加の成長・選択肢補正と、そのペアでしか起きない化学反応イベント（重み 2）が解放される。
- 突発イベントは 78 種。キャラ本人が育成対象／相棒のときはそのキャラの登場イベントを除外し、マスター・海外選手のイベントは新英雄大戦／W杯でのみ発生。

割り当てルール：キャラごとに原作の格を (floor, peak) で定義し、PWC でのレアリティ（★1→floor … ★5→peak）で内挿（`tools/build_cards.js` の `BAND`）。★4FLOW 由来は FLOW 突入率 +15%・FLOW ボーナス +5pt。PWC に選手カードが無い35キャラはストーリー段階別に複数個体を生成。

**カード画像について**：原作のキャラクター画像は同梱しない（個人使用の許諾を口頭で受けても、GitHub / claude.ai 経由で配布されるリポジトリ・Artifact に第三者の著作物を組み込むことは本作の作者側で権利を確認できないため）。各カードは生成 SVG アートを持ち、利用者が権利を持つ画像は次の 3 通りで取り込める。

## 主要な数式

- 初期値 = レア基準値[24…100]（星上げ後の段階）× 個性 × (主タイプ 1.3 / 他 0.95) × (1 + 0.05×限界突破) × (1 + 0.01×熟練度Lv) × (1 + 入寮前トレーニング)
- 成長補正 = レア基準[0.90…1.62] × (0.7 + 0.3×個性) × (主タイプ 1.12) × (1 + 育成方針 + アドバイザー + 練習理論 + 熟練度 + 相棒 + ペア)
- 練習獲得量 = (基礎値×編環境倍率[1/2.5/6/12/26] + 現在値×0.006) × (1 + 0.05×所持スキル数) × 成長補正 × (1 + 0.03×限界突破) × HP効率 × コンディション × 化学反応(指定属性 ×1.25)
- Climax 成功率：r = 対応2ステータス合計 ÷ 敵レート。r < 0.7 は 0%。基礎 = sigmoid(6×(r−1))。スキル・固有エゴ・アドバイザー・クラブ・ポジション適性・ノートは失敗率を割合で削る乗算補正、FLOW は +20pt 加算。上限 92%（単発試練は除外）。
- 年俸 = ゴール × 編別単価[30万/80万/200万/600万/1,500万] × (1 + 0.04×スキル数 + スピード系加算) × 圧倒度(1 + 0.25×min(2, r−1)) × MVP(1.5) × FLOW成功(1.2) × 代理人契約
- BLランキング = 300 × (編基準値 ÷ 合計ステータス)²

## 仕様書からの補完・変更点

- レアリティは仕様書の8段階と提供割合を採用し、PWC の全カードをその8段階に写像した（PWC 自体は ★1〜★5+FLOW の6段階）。
- 「1 編 = 1 回の育成」構造：卒業生プール、第四編卒業生 5 人による決戦、決戦の起用上限。
- 永続強化（エゴ強化・星上げ・熟練度）と相棒（化学反応ペア）を追加。
- 章を節に分割し原作の全試合を再現。二次選考の「奪われる」「指名」を分岐として実装。
- スキル補正は乗算（失敗率削減）、スキル数による練習倍率は線形。
- 引き分け即死ルールは FIFA W杯（4 Climax）で機能。W杯決勝T 以降と FIFA W杯は原作未到達の if。
