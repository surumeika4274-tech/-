# BLUE LOCK PWC : EGOIST ROGUELITE

> 本ゲームは原作のブルーロックを忠実に再現した、『ブルーロックPWC』の改変版である

漫画『ブルーロック』原作準拠の **超高難度ローグライト育成サッカーシミュレーション**（SPA）。
依存ライブラリなしの HTML / CSS / JavaScript で動作する。

## すぐに遊ぶ

- **単一ファイル版**：`dist/bluelock-pwc-egoist.html` をブラウザで開くだけ（CSS/JS 全インライン。フォントのみ Google Fonts、未接続時はシステムフォント）。
- **開発版**：`python3 -m http.server 8080` → http://localhost:8080/ （`index.html`）。
- セーブは `localStorage`（キー `bl_pwc_egoist_save_v3`）。行動のたびに不可逆で上書きされる。

割り当てルール：キャラごとに原作の格を (floor, peak) で定義し、PWC でのレアリティ（★1→floor、★2→+25%、★3→+50%、★4／★4FLOW→+80%、★5→peak）で内挿（`tools/build_cards.js` の `BAND`）。★4FLOW 由来のカードは FLOW 突入率 +15%・FLOW ボーナス +5pt。PWC に選手カードが無い35キャラ（ノア／絵心if／スナッフィー／ラヴィーニョ／プリンス／カイザー／ネス／ロレンツォ／シュヴァリエ、青い監獄組20名、U-20 各国代表6名）は「改変版オリジナル」として、若手時代／二次選考／新英雄大戦／マスター等のストーリー段階別に複数個体を生成。

**カード画像について**：原作のキャラクター画像は著作物のため同梱しない。各カードはタイプ色・レアリティ枠（★7以上はホロ）・姓の頭文字エンブレム・ストライカーのシルエット（個体ごとに傾き／反転）で生成した SVG アートを持つ。カード詳細の「画像を設定」で、利用者が権利を持つ画像を端末内に縮小保存（160×200 JPEG、1枚 60KB・合計 3MB 上限）し、そのキャラの全カードに表示できる。

## 主要な数式

- 初期値 = レア基準値[24…100] × 個性 × (主タイプ 1.3 / 他 0.95) × (1 + 0.05×限界突破)
- 成長補正 = レア基準[0.90…1.62] × (0.7 + 0.3×個性) × (主タイプ 1.12)
- 練習獲得量 = (基礎値×章環境倍率[1/1/2.5/6/12/26] + 現在値×0.006) × (1 + 0.05×所持スキル数) × 成長補正 × (1 + 0.03×限界突破) × HP効率 × コンディション × 化学反応(指定属性 ×1.25)
- Climax 成功率：r = 対応2ステータス合計 ÷ 敵レート。r < 0.7 は 0%（補正無効）。基礎 = sigmoid(6×(r−1))。スキル・固有エゴ・アドバイザー・クラブ・ノートは失敗率を割合で削る乗算補正、FLOW は +20pt 加算（★4FLOW 由来 +25pt）。
- 年俸 = ゴール × 章別単価 × (1 + 0.04×スキル数 + スピード系加算) × MVP(1.5) × FLOW成功(1.2)
- BLランキング = 300 × (章基準値 ÷ 合計ステータス)²

## システム一覧

化学反応練習（毎週の指定属性 ×1.25）／ポジション適性（第1ポジション対応の選択肢 +2%）／コンディション／固有覚醒スキル（76キャラ全員）／生成カードアートと画像取り込み／アドバイザー（実績で解放）／実績24種／BLランキング／図鑑／RUN履歴／結果コピー／効果音／キーボード操作（1〜5 練習・R 休養・S 購買部・A〜D 選択）／殿堂入り選手の FIFA ワールドカップ（4 Climax × 4連戦、一発勝負）。

## 仕様書からの補完・変更点

- レアリティは仕様書の8段階と提供割合を採用し、PWC の全カードをその8段階に写像した（PWC 自体は ★1〜★5+FLOW の6段階）。
- 章を節に分割し原作の全試合を再現。二次選考の「奪われる」「指名」を分岐として実装。
- スキル補正は乗算（失敗率削減）、スキル数による練習倍率は線形。
- 引き分け即死ルールは FIFA W杯（4 Climax）で機能。W杯決勝T 以降と FIFA W杯は原作未到達の if。
