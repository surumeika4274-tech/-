# BLUE LOCK PWC : EGOIST ROGUELITE

> 本ゲームは原作のブルーロックを忠実に再現した、『ブルーロックPWC』の改変版である

漫画『ブルーロック』原作準拠の **超高難度ローグライト育成サッカーシミュレーション**（SPA）。
依存ライブラリなしの素の HTML / CSS / JavaScript で動作し、`index.html` を開くだけでプレイできる。

## 起動

```bash
# 任意の静的サーバで公開（例）
python3 -m http.server 8080
# → http://localhost:8080/
```

`index.html` をブラウザで直接開いても動作する（ES Modules を使っていないため `file://` でも可）。
セーブデータは `localStorage`（キー `bl_pwc_egoist_save_v1`）に保存される。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | エントリ。`js/data.js` → `js/engine.js` → `js/ui.js` の順で読み込む |
| `js/data.js` | 静的データ：キャラ（★1〜★8）、スキル、章、購買部、突発イベント、W杯、調整パラメータ |
| `js/engine.js` | ゲームロジック（DOM 非依存）：成長計算、Climax 判定、FLOW、スキル覚醒、査定、ガチャ、セーブ、W杯 |
| `js/ui.js` | 画面描画とクリック処理（`data-action` 委譲） |
| `css/style.css` | スタイル（ダークテーマ、FLOW 時の白黒反転＋赤オーラ、モバイル対応） |
| `tools/sim.js` | バランス検証：貪欲AIで各キャラの章別生存率を推定 `node tools/sim.js 400` |
| `tools/power.js` | 章ごとの最良選択肢パワー分布を計測（敵レート設定用） |
| `tools/trace.js` | 1 RUN のステータス推移をトレース `node tools/trace.js nagi 7` |

## ゲームの流れ

1. **ロビー**：初回起動で ★1 潔世一（初期）と 1,500 Ego Gems を付与。ガチャ（単発150 / 10連1500、天井なし）または所持キャラから 1 名を選んで RUN 開始。
2. **育成フェーズ**：画面上部に「第〇章：公式戦まで あと〇週」。練習5種・休養は **1クリック＝即1週消費**、確認ダイアログなし。行動の瞬間に上書きオートセーブ（リロードでのやり直し不可）。購買部は週を消費せず、購入＝即時適用・買いだめ不可。
3. **試合フェーズ**：「あと0週」で暗転して強制突入。3回の Climax で A/B/C（＋INT系上位スキル所持時のみ D メタビジョン）を選択。成功率はリアルタイム計算で表示され、選択した瞬間に判定・保存。
4. **査定・選別**：年俸（Bid）査定と足切り判定。生存で Ego Gems +500、除籍で到達章×300 の補償ジェムを得てロビーへ強制送還（育成データ抹消）。
5. **殿堂入り**：第5章を 3対0 で完全制覇した選手は永続保存され、**FIFAワールドカップ（成人A代表・世界決戦モード）** に一度だけ出撃できる（4 Climax × 4 連戦、2-2 は引き分け即死）。

## 主要な数式（`js/data.js` の `PARAMS` で調整可能）

- **練習獲得量** = `(基礎値 × 章環境倍率 + 現在値 × 複利率) × 1.05^所持スキル数 × キャラ成長補正 × (1 + 0.03 × 限界突破数) × HP効率 × プロテイン(2)`
  - 章環境倍率：1 / 2.5 / 6 / 12 / 28（後半ほど爆発的にインフレ）
  - HP効率：50%以上 1.0、30〜49% 0.5、30%未満 0.35（かつ 40% で靭帯断裂＝即除籍）
- **Climax 成功率**：`比率 r = (対応2ステータス合計) ÷ 敵レート`。`r < 0.7` は補正一切無視で **0%**。それ以外は `sigmoid(10 × (r − 1))` を基礎値とし、スキル・固有エゴ・アナライズノートは「失敗率を割合で削る」乗算補正、FLOW は +20pt 加算。
- **FLOW**：最良選択肢が 25〜40% のとき 25%（キャラ補正あり）で突入。成功時はスキル確定覚醒。
- **コールド負け**：必要成功数の達成が数学的に不可能になった瞬間、残りの Climax を行わず打ち切り。第5章は 1 敗で即終了。
- **年俸**：`ゴール数 × 章別単価 × (1 + 0.04 × スキル数 + スピード系加算) × MVP(3/3で1.5) × FLOW成功(1.2)`。第4章は累計 3 億円以上が足切り。

## バランス（`node tools/sim.js 600` による推定・貪欲AI・限界突破なし）

| レア | 代表 | 完全制覇率 |
| --- | --- | --- |
| ★8 | ノエル・ノア / 絵心甚八 | 約 65〜73% |
| ★7 | ロキ / スナッフィー | 約 55〜60% |
| ★6 | カイザー / 冴 | 約 16〜32% |
| ★5 | 凛 / 士道 | 約 7〜9% |
| ★4 | 凪 / 馬狼 | 約 4〜10% |
| ★3 以下 | 蜂楽 / 千切 / ★2 / ★1 | ほぼ 0%（限界突破の蓄積が前提） |

★1 潔世一（初期）の第1章生存率は約 82%、第2章は約 9%。除籍で得た補償ジェムでガチャを回し、
限界突破（初期値 +5% / 成長補正 +3% を周回を跨いで蓄積）を重ねることで到達章を伸ばす設計。

## 仕様書からの補完・変更点（自律的改善の範囲）

- スキル補正を単純加算ではなく「失敗率の乗算的削減」にした（上位レアで 100% に張り付き緊張感が消えるのを防止）。「完全ゼロの壁」は補正無効の絶対ルール。
- 限界突破に「成長補正 +3%/回」を追加（初期値 +5% だけでは後半章のインフレに埋もれ、周回蓄積の意味が失われるため）。
- 引き分け即死ルールは 3 Climax 制の本編では数学的に発生しないため、W杯モードを 4 Climax 制にして 2-2＝即時敗北として機能させた。
- W杯は殿堂入り選手ごとに一発勝負（敗退で挑戦権喪失、記録は殿堂に残る）。
- 育成中でもロビー（ガチャ等）へ移動可能だが、RUN の放棄・リセットは不可。
