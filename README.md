# BLUE LOCK PWC : EGOIST ROGUELITE

> 本ゲームは原作のブルーロックを忠実に再現した、『ブルーロックPWC』の改変版である

漫画『ブルーロック』原作準拠の **超高難度ローグライト育成サッカーシミュレーション**（SPA）。
依存ライブラリなしの HTML / CSS / JavaScript で動作する。

『ブルーロックPWC』が 1 回の育成で完結するのに対し、本作は **五編（一次選考 → 二次選考 → 三次選考 → 新英雄大戦 → U-20 ワールドカップ）にわたって同一選手を 5 回育成し直し**、最終的に世界一を目指す構成。編ごとに育成方針を選び直し、編末に査定（足切り＋編評価ランク）を受ける。

## すぐに遊ぶ

- **単一ファイル版**：`dist/bluelock-pwc-egoist.html` をブラウザで開くだけ（CSS/JS 全インライン。フォントのみ Google Fonts、未接続時はシステムフォント）。
- **開発版**：`python3 -m http.server 8080` → http://localhost:8080/ （`index.html`）。
- セーブは `localStorage`（キー `bl_pwc_egoist_save_v4`）。行動のたびに不可逆で上書きされる。

割り当てルール：キャラごとに原作の格を (floor, peak) で定義し、PWC でのレアリティ（★1→floor、★2→+25%、★3→+50%、★4／★4FLOW→+80%、★5→peak）で内挿（`tools/build_cards.js` の `BAND`）。★4FLOW 由来のカードは FLOW 突入率 +15%・FLOW ボーナス +5pt。PWC に選手カードが無い35キャラ（ノア／絵心if／スナッフィー／ラヴィーニョ／プリンス／カイザー／ネス／ロレンツォ／シュヴァリエ、青い監獄組20名、U-20 各国代表6名）は「改変版オリジナル」として、若手時代／二次選考／新英雄大戦／マスター等のストーリー段階別に複数個体を生成。

**カード画像について**：原作のキャラクター画像は著作物のため同梱しない（個人使用であっても GitHub / claude.ai 経由の配布は個人使用の範囲を超えるため）。各カードはタイプ色・レアリティ枠（★7以上はホロ）・姓の頭文字エンブレム・ストライカーのシルエット（個体ごとに傾き／反転）で生成した SVG アートを持つ。利用者が権利を持つ画像は次の 2 通りで取り込める。

- **単体**：カード詳細の「画像を設定」→ 端末内に縮小保存（160×200 JPEG、1枚 60KB・合計 3MB 上限）。同キャラの全カードに表示。
- **一括**：所持選手タブの「画像を一括取り込み」→ 複数ファイルを選択。ファイル名（例 `isagi.png`、`潔世一.jpg`、`rin_itoshi.webp`）からキャラを自動判定。

各編の開始時に **育成方針**（決定力特化／戦術特化／快速特化／バランス）を選び直す。編末には足切り判定に加え、合計ステータス ÷ 編基準値（170 / 700 / 2,500 / 6,000 / 20,000）による **編評価ランク**（SS ≥ 3.0 / S ≥ 2.2 / A ≥ 1.6 / B ≥ 1.2 / C ≥ 0.9 / D）が付き、RUN 履歴に 5 編分の並びで記録される。

## 主要な数式

- 初期値 = レア基準値[24…100] × 個性 × (主タイプ 1.3 / 他 0.95) × (1 + 0.05×限界突破)
- 成長補正 = レア基準[0.90…1.62] × (0.7 + 0.3×個性) × (主タイプ 1.12) × (1 + 育成方針 ± アドバイザー)
- 練習獲得量 = (基礎値×編環境倍率[1/2.5/6/12/26] + 現在値×0.006) × (1 + 0.05×所持スキル数) × 成長補正 × (1 + 0.03×限界突破) × HP効率 × コンディション × 化学反応(指定属性 ×1.25)
- Climax 成功率：r = 対応2ステータス合計 ÷ 敵レート。r < 0.7 は 0%（補正無効）。基礎 = sigmoid(6×(r−1))。スキル・固有エゴ・アドバイザー・クラブ・ポジション適性・ノートは失敗率を割合で削る乗算補正、FLOW は +20pt 加算（★4FLOW 由来 +25pt）。上限 92%（単発試練は除外）。
- 年俸 = ゴール × 編別単価[30万/80万/200万/600万/1,500万] × (1 + 0.04×スキル数 + スピード系加算) × 圧倒度(1 + 0.25×min(2, r−1)) × MVP(1.5) × FLOW成功(1.2)。原作の入札上位（2.4億）が ★7 の新英雄大戦終了時の中央値〜上位に相当する尺度
- BLランキング = 300 × (編基準値 ÷ 合計ステータス)²

## システム一覧

- **育成**：1クリック＝1週。5属性練習／おまかせ練習（次の試合に最適な属性を自動選択）／休養／購買部（週消費なし）。化学反応練習（毎週の指定属性 ×1.25）、コンディション、HP と故障（30%未満で練習すると 40% で選手生命終了）。
- **試合**：3 Climax 制、選択肢 A〜D、0% の壁、FLOW（25〜40% 帯で突入判定）、スキル覚醒（無制限スタック、重複 35%）、固有覚醒スキル（76キャラ全員）、コールド打ち切り、ゴール時カットイン。
- **メタ**：Ego Gems と 8段階スカウト（単発 150 / 10連 1,500・天井なし）、限界突破（初期値 +5%・成長 +3%／回・周回を跨いで永続）、**エゴ・ピース**（再排出時に段階別に獲得、交換所で任意カードと交換）、アドバイザー7名（実績で解放）、実績27種（合計 9,400 ジェム）、BLランキング、図鑑、RUN 履歴（編評価ランク付き）、結果コピー。
- **エンドゲーム**：殿堂入り選手の FIFA ワールドカップ（4 Climax × 4連戦、一発勝負、引き分け即死）。
- **演出・操作**：生成カードアート、利用者画像の単体／一括取り込み、編ごとの背景、WebAudio 効果音（ON/OFF）、キーボード操作（1〜5 練習・R 休養・S 購買部・A〜D 選択・Esc 閉じる）、`prefers-reduced-motion` 対応。

## 仕様書からの補完・変更点

- レアリティは仕様書の8段階と提供割合を採用し、PWC の全カードをその8段階に写像した（PWC 自体は ★1〜★5+FLOW の6段階）。
- 章を「五編」に再編（入寮テストは第一編の先頭節）。各編で育成方針を選び直し、編末に査定と編評価ランク。
- 章を節に分割し原作の全試合を再現。二次選考の「奪われる」「指名」を分岐として実装。
- スキル補正は乗算（失敗率削減）、スキル数による練習倍率は線形。
- 引き分け即死ルールは FIFA W杯（4 Climax）で機能。W杯決勝T 以降と FIFA W杯は原作未到達の if。
