# BLUE LOCK PWC : EGOIST ROGUELITE

> 本ゲームは原作のブルーロックを忠実に再現した、『ブルーロックPWC』の改変版である

漫画『ブルーロック』原作準拠の **超高難度ローグライト育成サッカーシミュレーション**（SPA）。
依存ライブラリなしの素の HTML / CSS / JavaScript で動作し、`index.html` を開くだけでプレイできる。

## 起動

```bash
python3 -m http.server 8080   # → http://localhost:8080/
```

`index.html` を直接開いても動作する（ES Modules 不使用）。セーブは `localStorage`（キー `bl_pwc_egoist_save_v2`）。

## PWC との同期

- **選手カード**：PWC の全170カード（41キャラ）をカード名・レアリティ・タイプ・ポジションごと収録。PWC の 7タイプ（キック／スピード／テクニック／賢さ／フィジカル／スタミナ／コンディション）を本作の 5属性（SHT／SPD／TEC／INT／PHY）に対応させ、スタミナ＝練習HP消費 -2、コンディション＝不調に落ちない・休養+10 の固有効果を付与。
- **レアリティ**：PWC 現行の ★1 / ★2 / ★3 / ★4 / ★4 FLOW / ★5 の6段階。★4 FLOW は FLOW 突入率 +15%・FLOW ボーナス +5pt。
- **初期配布**：PWC の ★1「潔世一【チームＺ】」（キックタイプ）と 1,500 Ego Gems。
- **アドバイザー**：PWC のアドバイザーカード7枚（絵心甚八／帝襟アンリ／ノエル・ノア／糸師冴／三笘薫／ジュリアン・ロキ／不乱蔦宏俊）を RUN 開始時に選択する支援枠として実装（5名は実績で解放）。
- **提供割合**：★3 3.5% / ★2 30% / ★1 66.5% は PWC サービス開始時の公表値。現行の ★4 / ★4 FLOW / ★5 の提供割合は公式サイト・攻略サイトのいずれにも数値が公開されていないため、★1 枠から ★4 2.5% / ★4 FLOW 0.5% / ★5 0.5% を割り当てた**推定値**（`js/data.js` の `RARITY[*].rate` で変更可能）。ガチャの必要ジェム数（150／1,500）は本作独自。

## 主要な数式（`js/data.js` の `PARAMS`）

- **カード初期値** = レア基準値 × キャラ個性 × (主タイプ 1.3 / 他 0.95) × (1 + 0.05×限界突破)
- **成長補正** = レア基準 × (0.7 + 0.3×個性) × (主タイプ 1.12)
- **練習獲得量** = (基礎値×章環境倍率[1/1/2.5/6/12/26] + 現在値×0.006) × (1 + 0.05×所持スキル数) × 成長補正 × (1 + 0.03×限界突破) × HP効率 × コンディション
- **Climax 成功率**：r = 対応2ステータス合計 ÷ 敵レート。r < 0.7 は補正無視で 0%。基礎 = sigmoid(6×(r−1))。スキル／固有エゴ／アドバイザー／クラブ／ノートは失敗率を割合で削る乗算補正、FLOW は +20pt 加算。
- **スキル覚醒**：成功時、対応系統で閾値を満たす最上位を覚醒。同スキル所持時の重複は 35%（FLOW 成功時は確定）。固有覚醒スキルは主属性 220 以上で成功、または FLOW 成功で発現。
- **年俸** = ゴール × 章別単価[0 / 300万 / 800万 / 2000万 / 6000万 / 1.5億] × (1 + 0.04×スキル数 + スピード系加算) × MVP(3/3で1.5) × FLOW成功(1.2)
- **BLランキング** = 300 × (章基準値 ÷ 合計ステータス)²（1〜300位）

## 追加システム

- コンディション（絶好調／好調／普通／不調）：練習で下がりやすく休養で上がる。獲得量とHP消費に影響。
- 固有覚醒スキル：41キャラ全員に個別の覚醒スキル（例：潔「メタビジョン・ダイレクト」、凪「神トラップ」、馬狼「邪道こそが王道」）。
- 実績24種：Ego Gems の獲得源であり、アドバイザー解放条件。
- 図鑑・RUN履歴・BLランキング・効果音・キーボード操作（1〜5 練習 / R 休養 / S 購買部 / A〜D 選択）。
- 殿堂入り選手の FIFA ワールドカップ（アルゼンチン→ブラジル→イングランド→ノエル・ノア率いるフランス、4 Climax×4連戦、一発勝負）。

## 仕様書からの補完・変更点

- 章を「節」に分割し、原作の全試合（入寮テスト〜U-20 W杯）を再現。二次選考は「敗北→奪われる」「凛の指名」を分岐として実装。
- スキル補正は乗算（失敗率削減）、スキル数による練習倍率は線形（1+0.05n）。指数にすると後半が発散するため。
- 引き分け即死ルールは 3 Climax 制では発生し得ないため、FIFA W杯（4 Climax）で機能させている。
- W杯決勝トーナメントの相手（ドイツ／スペイン／フランス）と FIFA W杯は原作未到達のため if 設定。
